# ときめきスイーツ図鑑

公開サイト: https://dacotahouse.github.io/tokimeki-sweets/

見た目や個性にときめくスイーツを日本語で紹介する静的サイトです。公開HTMLは9カテゴリー・各10品の計90商品です。

## 自動監視

GitHub Actions の [Weekly sweets link audit](.github/workflows/weekly-link-audit.yml) は、毎週月曜日の午前8:30（日本時間）に実行する設定です。Actions画面からの手動実行もできます。

- [scripts/validate_site.py](scripts/validate_site.py): 公開HTMLの9カテゴリー、各10商品、重複掲載、トップページ導線を検査。
- [scripts/check_links.py](scripts/check_links.py): サイト内リンクと楽天の商品ページのHTTP応答を検査し、MarkdownとJSONのレポートを作成。
- 結果はActions実行概要とArtifactsに保存（Artifactsは30日間保管）。

**HTTP 200は在庫ありを意味しません。** 403/429はアクセス制限の可能性があり、404/410も販売終了を確定しません。販売状況、商品規格、広告コードは別途確認が必要です。この監視処理は商品を削除・交換・公開しません。

## 安全な更新

現状の [build_site.py](build_site.py) と [catalog.json](catalog.json) は以前の6カテゴリー版を起点としており、現在の9カテゴリーを完全に再生成できる状態ではありません。そのまま実行すると公開HTMLが古い内容で上書きされるため、9カテゴリーの公開ファイルがある場合は安全停止する設定です。

再生成を有効にする前に、9カテゴリーの全商品、テンプレート、特集、広告コード、画像を現行公開版と一致させてください。現段階では古い生成プログラムを日常の更新に使用しないでください。

紹介文・商品画像・広告コードについては [AGENTS.md](AGENTS.md) の方針を守り、架空の広告リンクや未確認の口コミ・在庫を掲載しません。
