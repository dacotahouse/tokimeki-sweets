# ときめきスイーツ図鑑

「映えるスイーツ」「キュートなお菓子」「ギフトスイーツ」を各10品、計30品紹介する静的サイトです。楽天市場と一部のYahoo!ショッピングの購入ページには、取得済みのもしもアフィリエイト広告コードを使っています。

## AIによる更新

- 商品・写真の参照先・取得済み広告コード・価格確認日・紹介文は `catalog.json` に保存しています。
- ページ構成と生成処理は `build_site.py`、共通デザインは `style.css`、検索は `site.js` です。カテゴリーを公開するときは `build_site.py` の `PUBLISHED` を更新し、既存カテゴリーとの商品重複がないことを確認してください。
- `python build_site.py` でページを再生成します。価格・限定販売の情報を更新する場合は表示中の確認日も見直してください。
- 既存の商品を差し替える場合は、もしもアフィリエイトで実際に広告コードを取得し、商品名・販売元・内容量を照合してから編集してください。
- 公開前にスマホ表示・商品画像・広告リンク・内部リンク・検索を検証してください。

## 掲載方針

- 架空のアフィリエイトリンクや識別子は作りません。
- 商品写真はアフィリエイト広告からの画像を使用し、色・形・文字など画像内容の加工は行いません。
- 体験していない実食談、根拠のないレビューや順位は掲載しません。
- ふるさと納税、食品でない雑貨・ミニチュアは対象外です。
- 商品選定は見た目、商品の独自性、目的との相性を重視します。
- 季節限定と秋冬向けの定番を区別します。
